Setup

Get your lecture calendar and cards into Janki in a few minutes.

  1. Install Janki from the Janki page, then restart Anki.

  2. Open LEO and go to your Profile.

  3. Set Enable Public Calendar Feed to Yes, then copy the ICS URL above it.

  4. Open Janki's settings: click the settings gear (top right), or Tools → Janki: Settings…. Go to Lectures → Calendar and paste the URL into File/URL.

  5. Download one of these spreadsheets as an .xlsx (in Google Sheets: File → Download → Microsoft Excel):

    • Lecture tag sheet
    • AnKing tag sheet (better for AnKing)

  6. In Lectures → Sources, click Browse… next to Base file and pick the .xlsx you downloaded. Then tick the decks you use under Sources.

    AnKing can slow things down, especially on older computers. If Anki feels laggy, untick AnKing.

  7. Done. Open the Calendar in Janki to see your classes, or use Tools → Load today's lectures to unsuspend today's cards.
